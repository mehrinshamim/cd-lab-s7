# CSL 411 Compiler Lab (cd-lab-s7)

**Model Engineering College, Thrikkakara**

## Lab Schedule

**Introduction:** 03-07-26

### Cycle I
*Submit by 22-07-26 / 24-07-26*

1. Write a program to find the ε-closure of all states of any given NFA with ε transitions.
2. Write a program to convert an NFA with ε transitions to an NFA without ε transitions.
3. Write a program to convert an NFA to a DFA.
4. Write a program to minimize any given DFA.

### Cycle II
*Submit by 29-07-26 / 31-07-26*

5. Design and implement a lexical analyzer for a given language using C. It should ignore redundant spaces, tabs and newlines.
6. Write a Lex program to recognize all strings which do not contain the first four characters of your name as a substring.
7. Write a YACC program to recognize a valid variable which starts with a letter followed by any number of letters or digits.
8. Implement a calculator using Lex and YACC.
9. Convert the BNF rules into YACC form and write code to generate an abstract syntax tree.
10. Write a YACC program to check the syntax of the `for` statement in C.

### Cycle III
*Submit by 19-08-26 / 21-08-26*

11. Develop an operator precedence parser for a given language.
12. Write a program to simulate First and Follow of any given grammar.
13. Construct a recursive descent parser for an expression.
14. Construct a shift-reduce parser for a given language.

### Cycle IV
*Submit by 16-09-26 / 18-09-26*

15. Implement intermediate code generation for simple expressions.
16. Implement the back end of the compiler, which takes the three-address code and produces 8086 assembly instructions that can be assembled and run using an 8086 assembler. The target instructions can be simple `mov`, `add`, `sub`, `jmp`, etc.
